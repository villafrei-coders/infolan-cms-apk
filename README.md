## Publicar una versión nueva
1. Reemplazar los archivos en la carpeta `apk/` (mismos nombres).
2. Cambiar el número en `VERSION`.
3. Subir los cambios: GitHub crea la versión y los enlaces de arriba pasan a la nueva.
